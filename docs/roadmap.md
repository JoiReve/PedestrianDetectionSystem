## 方向

1. **健壮性**
	单帧失败不该拖垮整段视频：坏输入与异常都走"跳过并告知"的路子。

2. **播放与交互体验**
	帧节奏贴合源本身，而不是"能多快解多快"；暂停 / 步进 / 截图补齐；画面上让进度、帧号与状态可见。
	`--no-show` 解决的是无头运行，不是播放控制。

3. **输出管道**
	逐帧检测结果已能通过 `--dump` 落成 CSV，程序也能用 `--no-show` 脱离图形界面运行；下一步补带框视频 / 标注帧导出，让输出形态更完整。

4. **性能 —— 先量后优**
	分阶段计时已覆盖整帧、读帧、推理链路、绘制与显示（已落地：`StageTimeTracker` + 冷启动 / 稳态报表），下一步在数据指导下做缓冲复用、跳帧、多线程。
	这个顺序不能反：没有数据就上并行属于过早优化。

5. **输入源与能力扩展**
	摄像头 / RTSP、ROI、简单 IoU 跟踪；顺带检验工厂这层抽象的扩展成本到底值不值。
